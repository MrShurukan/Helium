# UART TX: принятый и реализованный API

Статус: принят пользователем и реализован 27 октября 2026. Polling TX, 8N1;
общие контракты вызовов и предупреждения — [CALL_EFFECTS.md](CALL_EFFECTS.md).
Имя файла сохранено для существующих ссылок.

```text
device debug = UART0 {
    baud: 38400,
    mode: TX,
}

setup {
    debug.write_byte(72);
    debug.write_byte(105);
    debug.flush();
}

loop {
    noInterrupt {
        var accepted: bool = debug.try_write_byte(46);
    }
}
```

Реализован фиксированный формат 8N1 для первого этапа, CPU clock через существующий
`--cpu-hz`. Конфигурация статическая; RX, прерывания UART, очереди и изменение baud
во время работы пока отсутствуют. Имя `debug` выбирает пользователь. TX-пин UART0
резервируется устройством и конфликтует с обычным GPIO; RX-пин в TX-only не захватывается.
Сам UART0 нельзя зарезервировать второй раз.

Операции:

- `try_write_byte(value: u8): bool`: одна проверка готовности, запись при готовности,
  иначе false без записи. Без ожидания.
- `write_byte(value: u8)`: polling до возможности принять байт, затем запись.
- `flush()`: polling до полного завершения предыдущей передачи; пустой flush возвращается.

Инициализация до setup. Все три операции допустимы в setup, loop и noInterrupt;
прогресс polling-TX не зависит от ISR. В ISR блокирующие write_byte и flush
разрешены с W_ISR_BLOCKING, включая вызовы через helpers. Предупреждение нельзя
отключить. try_write_byte не блокируется и не вызывает этого предупреждения.
Если main и ISR используют один UART, доступ main должен быть защищён noInterrupt.
Для общей последовательности байтов защитить всю последовательность. Обычный helper
не наследует защиту вызывающего: используйте собственный блок или noInterrupt fn.

Выбор baud перебирает normal/U2X и допустимые UBRR, сравнивает ошибки рациональной
арифметикой без float; при равенстве предпочитает normal. Ошибка выше 2% — E_DEVICE.
Отчёт показывает фактический baud и отклонение. Это предел ошибки делителя при заданной
частоте, не гарантия связи при неизвестной погрешности кварца или несовместимом приёмнике.
38400 при 16 MHz даёт UBRR=25, U2X=0, примерно 38461.54 baud (+0.1603%).
115200 при 16 MHz пока отвергается (лучший вариант около +2.124%).

Короткая операция проверки UDRE/записи UDR/очистки TXC сохраняет SREG и запрещает IRQ.
Ожидание работает вне этой внутренней защиты. TXC очищается записью единицы после UDR;
flush ждёт именно завершения передачи. Один внутренний байт состояния на UART позволяет
пустому flush вернуться сразу. GPIO PD1 резервируется, PD0 остаётся свободным.

Основание регистров/флагов — [ATmega328P datasheet, USART](https://ww1.microchip.com/downloads/en/DeviceDoc/Atmel-7810-Automotive-Microcontrollers-ATmega328P_Datasheet.pdf).
Машинные тесты используют AVR8js: callback отмечает запись UDR, модель не воспроизводит
полный аппаратный двойной буфер. Проверки не доказывают физическую доставку или точный
wire timing. Плата в этой итерации не прошивалась. IR-интерпретатор UART не моделирует
и явно отказывается исполнять соответствующую операцию.

Байтовые литералы/целые u8 достаточны для первой реализации. Строки, интерполяция,
форматтер и общий интерфейс software UART не вводятся попутно.

Следующий отдельный вопрос (этап reusable helper): форма статического параметра,
например `fn send(device output: UartTx, value: u8)`. Это ещё не утверждённый синтаксис;
параметр не должен превращаться в runtime-указатель или копируемый ресурс. До его
реализации TX-примитив не называется готовой библиотечной системой.

## Проверка реализации

Полный gate: 158 тестов в debug и 158 в release, fmt и Clippy. UART-сценарии
проверяют setup без IRQ, вызовы из ISR с возвратом к main, обычный main с включёнными
IRQ и вложенный noInterrupt при LLVM none/speed/size. Проверены типы, резервирование,
ошибочный IR, цепочки helpers, предупреждения и успешный CLI HEX при warning.

`examples/uart-tx.he`, --opt size, 16 MHz: Flash 270 байт, статическая SRAM 1 байт.
Это итог конкретного связанного ELF, включая startup; максимальный стек unknown.
Локальный журнал полного прогона: build/uart-full-gate-final.log (не коммитится).
