# Helium

Helium is a special language created specifically for AVR programming.
It's a hobby project of mine, so let's have fun while it lasts, shall we?

It's built with Rust. Produces an assembly file, which is then processed with 
[avra assembler](https://github.com/Ro5bert/avra) and uploaded via avrdude.

Avra and avrdude executables **must be available on path**.

This page is _planned_ to be updated as more and more of the language is developed.
But you know how pet-projects sometimes go...
